# Greetings & set phrases

These are memorized wholes, not grammar. Don't analyze them yet — 今日は literally asks "as for today…?" and trails off, which is interesting and useless right now.

## Notes

### 今日は（こんにちは）
Written は, said わ — same particle rule as [[g-wa-topic]]. Not used first thing in the morning (おはよう) or at night (こんばんは).

### 有難う（ありがとう）
Casual on its own. ありがとうございます is the polite default with anyone you don't know. Almost always written in kana.

### お願いします（おねがいします）
Enormously useful and has no clean English equivalent. Covers "please do that for me," "I'd like that one," "nice to work with you," and "yes please" at a counter. Learn it early, use it constantly.
