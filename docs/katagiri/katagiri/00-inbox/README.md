# Inbox

Dump anything here with zero structure. Half-heard words, screenshots, "what was that phrase in ep 3", questions, Codex session transcripts.

Rule: **capture must be frictionless or you won't do it.** Structure is applied later, by `triage_inbox`, not by you in the moment.

Files here are expected to be messy and temporary. Empty inbox is the goal, not a clean inbox.
