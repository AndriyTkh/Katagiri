# Grammar

One note per concept. Each carries an `understanding:` level from 1 to 5 that you **raise over time** — you do not "finish" a grammar point. は vs が at level 2 with three months of listening behind you is a different conversation than at level 1.

## Understanding scale

1. I've read the explanation.
2. I recognise it when I hear it.
3. I can produce it when I plan a sentence.
4. I produce it correctly without thinking.
5. I notice when *others* get it subtly wrong.
