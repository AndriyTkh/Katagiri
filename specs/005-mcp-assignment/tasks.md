**✅ SOURCE OF TRUTH**: this tasks.md (spec-kit). This feature has **no beads history**, so there are no `[was: kata-*]` refs.

Max parallel width is three lanes, and the lanes never overlap in files: `wt/005-agent` owns `agent/**`, `wt/005-demo` owns the demo fixtures plus `scripts/build_demo_db.py`, `wt/005-docs` owns `docs/assignment/**` plus the two remaining `scripts/`. Each task's Read list is its complete context: an executing agent needs no beads, no other lane's files, and no artifacts from features 003/004/006.
