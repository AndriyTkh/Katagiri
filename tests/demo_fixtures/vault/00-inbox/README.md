# Inbox

Raw capture goes here before it is triaged into the rest of the vault —
mined sentences, quick vocabulary notes, things to look up later. Empty
by default in this demo fixture; it exists so the vault tree matches the
shape a real Katagiri vault has (mirrors `docs/katagiri/katagiri/
00-inbox/README.md` in the real vault) and so a `triage_inbox` demo call
has a real, if empty, directory to look at instead of a missing path.

(Synthetic demo fixture for specs/005-mcp-assignment — no personal
content.)
